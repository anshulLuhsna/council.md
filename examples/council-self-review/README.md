# council-self-review

This example shows `council.md` reviewing itself.

The topic is central to the project:

> Should `council.md` reframe itself from runtime-free to file-first, invariant-first, runtime-optional?

This example is meant to show:

- `council.md` can critique its own protocol honestly
- the council does not have to collapse into self-validation
- disagreement can be preserved without turning into a fake verdict
- the human can record a direction and follow-up work

The important disagreements in this example are:

- whether the no-runtime framing is a core strength or a strategic liability
- whether files are a genuine epistemic mechanism or mostly a portable artifact format
- whether the workflow is too manual for repeat users
- whether the project should eventually have a reference runtime
