# council.md — Protocol specification v0.2

The specification is **split** so the **compliance contract** stays small and auditable:

| Document | Role |
|---|---|
| **[SPEC-core.md](SPEC-core.md)** | **Compliance contract** — filenames, phases, headings, synthesis/decision locations, minimum audit fields. **Read this first** to know if a fork is compatible. |
| **[SPEC-rules.md](SPEC-rules.md)** | **Operational detail** — voting order, blind workflow, quorum semantics, synthesizer behavior, locks, YAML examples, deprecation notes. |

Both files are **v0.2** and ship together. Same MIT license as the repository.

**Reading order:** **SPEC-core** → **SPEC-rules** when running or scaffolding a session.
